# ForgeFlow web

Next.js app for ForgeFlow (`apps/web`).

Use the **root** [README](../../README.md) for setup, demo steps, and API notes.

```bash
# from the monorepo root
pnpm install
pnpm --filter web dev
```

Runs at http://localhost:3000. Point `NEXT_PUBLIC_API_URL` at the Go API (see `.env.example`).
